/01Research position

Trust is not a property. It is a claim to be tested.

Does the test itself hold?

Pressure-test benchmarks with adversarial examples, and measure how much a metric’s design changes its own answer.

F/N—002

FactTrace

Chain-of-thought faithfulness / Aug 2026

Source ↗

A black-box factuality monitor that decomposes reasoning traces, retrieves evidence with FAISS, and labels each claim using NLI.

Dense retrieval and RoBERTa-large-MNLI raised claim-level accuracy from 78.5% to 87.7%. Unsupported claims clustered in later reasoning steps.

F/N—003

CalibCheck

Calibration & honesty evaluation / Aug 2026

Source ↗

An epistemic evaluation comparing verbalised self-reported confidence with raw next-token probability, scored through ECE, Brier score, and reliability diagrams.

The aggregate ECE looked mild. The domain view exposed sports as 57.5 points overconfident—the failure the average concealed.
