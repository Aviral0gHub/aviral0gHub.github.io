FactTrace — Claim-level factuality verification
Python · PyTorch · Sentence-Transformers · HuggingFace Transformers · FAISS

Decomposes multi-step agentic LLM reasoning into atomic claims, retrieves evidence via FAISS-based dense retrieval, and classifies each claim as supported, contradicted, or unverifiable using NLI-based entailment scoring. Failure analysis showed unsupported claims concentrate in later reasoning steps.

CalibCheck — Confidence calibration analysis
Python · HuggingFace Transformers · Anthropic API · Matplotlib

Measures whether an LLM's confidence actually tracks whether it's right, comparing verbalized self-reported confidence against raw next-token probability over answer choices. Breaks results down by topic domain, since aggregate calibration can hide systematic over- or under-confidence on specific subjects.

Last Translation Benchmark — Co-Author
with researchers from ETH Zürich, JHU, CUNI, UvA & KIT

Co-authoring an upcoming multilingual, multimodal factuality benchmark. Contributed adversarial multimodal inputs designed to break state-of-the-art models.

Limitations & Known Issues
Stated plainly, same as any model card should
  • CalibCheck's calibration numbers are from a synthetic baseline only — real verbalized-vs-raw-probability comparison is still pending a live run.
  • Evaluation work so far is primarily English-language; multilingual generalization beyond LTB's adversarial examples is untested.
  • Retrieval-based verification (FactTrace) depends on having a relevant evidence corpus available — behavior under fully closed-book conditions hasn't been benchmarked.
