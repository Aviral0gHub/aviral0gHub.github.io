FactTrace

Python · PyTorch · Sentence-Transformers · HuggingFace Transformers · FAISS

Claim-level factuality verification pipeline for agentic LLM reasoning traces — decomposes multi-step reasoning into atomic claims, retrieves evidence via FAISS-based dense retrieval, and classifies each claim as supported, contradicted, or unverifiable using NLI-based entailment scoring. Improved accuracy from 78.5% (lexical baseline) to 87.7% by swapping in dense retrieval and RoBERTa-large-MNLI entailment scoring; failure analysis showed unsupported claims concentrate in later reasoning steps.

EXHIBIT P-2 Trustworthy ML · Calibration

CalibCheck

Python · HuggingFace Transformers · Anthropic API · Matplotlib

Measures whether an LLM's confidence actually tracks whether it's right — comparing verbalized self-reported confidence against raw next-token probability over answer choices, using Expected Calibration Error, Brier score, and reliability diagrams. Results are also broken down by topic domain, since a model can look calibrated in aggregate while being systematically over- or under-confident on one specific subject.
